# Discovery and verification resources

These resources are for discovery, visual inspection or learning. Listing them does not mean their imagery was used in the analysis. Actual optical downloads remain Element 84 Earth Search; thermal downloads remain Planetary Computer, with scene metadata preserved.

| Resource | Role | Link / status |
|---|---|---|
| Copernicus Browser (instructor recommended) | Sentinel discovery and comparison; Sentinel-2 is not a direct thermal source | https://browser.dataspace.copernicus.eu/ ; documentation checked 6 Oct: https://documentation.dataspace.copernicus.eu/Applications/Browser.html |
| NASA Earthdata (instructor supplied) | Earth-observation discovery | https://earthdata.nasa.gov/dashboard ; exact dashboard destination not confirmed in this revision |
| NASA Worldview (additional suggestion) | Dataset viewing and comparison; choose suitable resolution | https://worldview.earthdata.nasa.gov/ ; supplied official documentation could not be retrieved in this revision |
| Bellingcat toolkit (instructor recommended) | Geolocation tool directory, not analysis data | https://bellingcat.gitbook.io/toolkit/categories/geolocation ; page checked 6 Oct |
| GEOINT directory 1 | Directory, not data source | https://start.me/p/RM2E1q/mapping-geospatial-intelligence-geoint ; supplied link, not rechecked |
| GEOINT directory 2 | Directory, not data source | https://start.me/p/Yayv8J/geo-int ; supplied link, not rechecked |
| General OSINT directory | Broader tools directory | https://start.me/p/0Pqbdg/osint-500-tools ; supplied link, not rechecked |

The bus-stop reference is Google Street View, capture March 2023, https://maps.app.goo.gl/gPEzxW3NFqErPWNP8. Historical evidence is distinct from current field verification. The package links to it and does not redistribute Street View screenshots. Google Geo guidance: https://about.google/brand-resource-center/products-and-services/geo-guidelines/ .

A future shadow tool would require verified geometry and local checks. Simulated shade is not measured temperature or proof of cooling. No additional portal supplied imagery for this revision.
