## Follow-up discipline

- If asked for an unmeasured count or effect: "We have not measured that yet; it remains Unknown. The next site assessment would document it."
- If asked for a result beyond two accepted thermal dates: state the time/resolution limits; do not infer a seasonal trend, causal cooling or personal exposure.
- If asked about exact historic class accuracy: eight clear broad patterns are not eight validated labels or an 8/18 accuracy score; the three overlapping potential disagreement flags are not confirmed model errors.
- If asked to demonstrate a control: use the unchanged offline map, and keep the prepared fallback. Never claim live success when a control is blocked.
- If asked about eligibility, shortlist or deadline: no invitation/slot is confirmed. The supplied review describes shortlisted-pitch timing and conflicting cutoff statements; the actual account guide/invitation must be checked through Nasser before a final form step.
